# Online Student Management Portal QA Reports

This repository contains the Week 1 test plan and Week 2 exploratory testing report for a hypothetical Online Student Management Portal. Both reports are editable Word documents prepared for the internship project.

The cases exercise registration, login, dashboard navigation, student profile viewing and editing, search, administrator CRUD, logout and session handling, responsive usability, keyboard accessibility, authorization boundaries, input handling, and safe error behavior. Each case includes an ID, module, type, priority, preconditions, test data, steps, expected result, actual-result placeholder, and initial Not Executed status.

All product behaviors and requirements are explicitly hypothetical planning assumptions. The sample names and `.test` email addresses are fictional. Do not replace them with real student data. Confirm role permissions, field rules, supported browsers, session policy, and accessibility target with the product owner before execution. Security scenarios are intended only for an authorized, isolated QA environment.

## Reports

- `Week_1_QA_Test_Plan_Online_Student_Management_Portal.docx` — editable report for review and submission.
- `Week_2_Exploratory_Testing_Report_Online_Student_Management_Portal.docx` — charter, time-boxed session notes, findings, and bug reports. Findings are clearly identified as simulated examples because no live application was provided.
